# Moderation & Safety

Moderation is a core platform feature.

## Moderation Actions

### User Actions
Users can:
- Report
- Block
- Mute
- Hide

### Moderator Actions
Moderators can:
- Remove content
- Lock discussion
- Warn user
- Mute user
- Suspend user from Space
- Ban user from Space
- Review reports

### Platform Actions
Platform administrators can:
- Suspend account
- Restrict account
- Remove illegal/unsafe content
- Delete Spaces
- Manage platform-wide reports

## Reporting

**Report flow:**
Report -> Select reason -> Optional details -> Submit -> Confirmation

**Reasons:**
Spam, Harassment, Hate, Sexual content, Violence, Self-harm, Illegal activity, Copyright, Misinformation, Other.

Do not expose unnecessary moderation details to the reporter.

## Safety

Core safety controls:
- Block
- Mute
- Report
- Message requests
- Privacy controls
- Account visibility
- Content warnings
- Moderation
- Age-appropriate protections
