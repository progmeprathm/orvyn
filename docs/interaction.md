# Interaction

## Comments & Replies

Comments support threaded conversation.

```text
Post
└── Comment
    ├── Reply
    │   └── Reply
    └── Reply
```

**Actions:**
- React
- Reply
- Edit own comment
- Delete own comment
- Report
- Hide

## Reactions

- **MVP:** Like / primary reaction
- **Future:** Multiple reactions, Custom Space reactions

Reaction counts should not dominate the interface.

## Following System

Users can follow other users.

Following affects:
- Home feed
- Recommendations
- Activity
- Notifications

Follow relationships should remain independent from Space membership.
